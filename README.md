# Void-Strike
Void Strike is a space shooter game. In which you have to test your survival skills while being constantly attacked by enemy ships. BTW if this project sucks it's because it's my first Godot game.

# Features
1) 10 different enemy types
2) Statistics
3) 12 Achievements
4) Audio/Control settings
5) Infinite Waves
6) Upgrade Shop

#  Play on Itch.io
https://github.com/judeweibley-cell/Void-Strike

# Preset Controls
Up - W
Down - S
Right - A
Left - D
Shoot - SPACE
Boost - SHIFT
Interact - LEFT CLICK
